구글 앱스 스크립트(GAS) 백엔드 자동 수집 가이드

                        
본 도구에서 검색한 데이터를 구글 시트에 자동으로 누적 저장하는 스크립트 코드입니다.

                    

                


                

                    
사용 방법:

                    
    
                        
  1. 구글 시트(Google Sheets)를 새로 생성합니다.
    2. 
                        
  2. 상단 메뉴에서 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
    3. 
                        
  3. 기존 코드를 모두 지우고 아래의 스크립트 코드를 복사하여 붙여넣습니다.
    4. 
                        
  4. 코드 내 SERVICE_KEY 항목에 본인의 공공데이터 API 키를 입력하고 저장 후 실행합니다.
    5. 
                    

                


                

                    
                    
// 구글 앱스 스크립트 (Google Apps Script) - 건축물대장 Hub 전용
function fetchBuildingRegisterHubData() {
  const SERVICE_KEY = "YOUR_PUBLIC_DATA_API_KEY_HERE"; // 공공데이터포털 인코딩 인증키
  const sigunguCd = "11680"; // 예: 강남구
  const bjdongCd = "10100";  // 예: 역삼동
  const bun = "0825";        // 4자리 맞춤 (예: 825 -> 0825)
  const ji = "0000";         // 4자리 맞춤
  
  const url = `https://apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo?serviceKey=${SERVICE_KEY}&sigunguCd=${sigunguCd}&bjdongCd=${bjdongCd}&bun=${bun}&ji=${ji}&_type=json&numOfRows=100`;
  
  try {
    const response = UrlFetchApp.fetch(url, { muteHttpExceptions: true });
    const json = JSON.parse(response.getContentText());
    const items = json.response.body.items.item;
    
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (!items || items.length === 0) {
      Logger.log("조회된 데이터가 없습니다.");
      return;
    }
    
    // 헤더 작성 (첫 줄)
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(Object.keys(items[0]));
    }
    
    // 데이터 행 추가
    items.forEach(item => {
      sheet.appendRow(Object.values(item));
    });
    
    Logger.log(`${items.length}건 수집 완료!`);
  } catch (e) {
    Logger.log("오류 발생: " + e.toString());
  }
}
