공공데이터 API 조회 도구

인증키만 넣으면 자주 쓰는 공공데이터를 바로 조회합니다

공공데이터포털 인증키 미설정

data.go.kr에서 활용신청 후 받은 키입니다. 공공데이터포털 API를 호출할 때만 쓰이고 이 브라우저(LocalStorage)에만 저장됩니다.

조회 항목

건물 주소 검색 및 파라미터 추출

공공데이터포털 API 활용 첫 번째 예시입니다(국토교통부 건축HUB 건축물대장정보). 카카오 주소 검색을 이용하면 법정동코드와 번지수가 자동으로 계산됩니다.

대장 종류:

국토교통부 건축물대장 API 서버와 통신 중입니다...

                        다른 공공데이터 API 직접 조회
                    

                    
공공데이터포털(data.go.kr)의 다른 API 주소와 요청변수를 직접 입력해 조회합니다. 요청변수는 활용신청한 API 상세 페이지의 요청변수 표를 보고 입력하세요. 위쪽 인증키 칸에 저장한 공공데이터포털 인증키(serviceKey)가 자동으로 붙습니다. 법제처 API는 [법제처] 탭에서 조회하세요.

                    
건축물대장 계열 API는 지(ji)를 빼고 번(bun)만 넣으면 같은 번지의 건물이 모두 조회됩니다.

공공데이터포털 인증키와 다른 값입니다. 법제처(open.law.go.kr) OPEN API 신청 화면에서 직접 정한 인증값을 입력하세요. 이 브라우저에만 저장됩니다.

처음 사용하는 방법

                        
인증키는 기관마다 따로 받습니다. 쓰려는 기관 탭에서 한 번만 입력하면 되고, 이 브라우저에만 저장됩니다.

                    

                


                
    
                    
  1. 
                        1
                        
    
                            
    기관 탭과 조회 항목 고르기
    
                            
    위쪽 탭에서 기관(공공데이터포털, 법제처)을 고르면, 그 기관에서 연결해 둔 조회 항목이 아래에 나옵니다. 공공데이터포털에는 건축물대장 빠른 조회와 다른 API 직접 조회가, 법제처에는 법령 검색과 고용노동부 법령해석이 있습니다.
    
                        
    
                    
    2. 
                    
  2. 
                        2
                        
    
                            
    기관별 인증키 받기
    
                            
    공공데이터포털: data.go.kr에 로그인해 쓰려는 API를 검색하고 [활용신청]을 누릅니다. 건축물대장은 국토교통부_건축HUB_건축물대장정보 서비스입니다. 승인 후 마이페이지의 해당 API 상세 화면에서 일반 인증키를 복사합니다. 승인 직후에는 반영까지 시간이 걸릴 수 있습니다.
    
                            
    법제처: open.law.go.kr의 OPEN API 신청에서 인증값(OC)을 직접 정해 신청합니다. 신청 후 마이페이지의 API인증키관리에서 확인할 수 있습니다.
    
                        
    
                    
    3. 
                    
  3. 
                        3
                        
    
                            
    기관 탭 위쪽 칸에 입력하고 조회
    
                            
    해당 기관 탭 맨 위의 인증키 칸에 붙여넣고 [저장]을 누릅니다. 건축물대장은 [주소 찾기]로 주소를 고른 뒤 대장 종류를 선택해 조회하고, [대장 서식]을 고르면 정부24 대장 모양으로 보고 인쇄할 수 있습니다. 법령은 법령명을 입력하거나 자주 보는 법령 버튼을 누릅니다.
    
                        
    
                    
    4. 
                


                

                    
알아두세요

                    
공공데이터포털 인증키와 법제처 인증값은 서로 바꿔 쓸 수 없습니다. 서울 열린데이터광장, 한국은행 ECOS처럼 키를 넣는 방식이 다른 포털은 아직 지원하지 않습니다.

                    
조회 결과는 참고용입니다. 공식 서류나 법적 효력이 필요하면 정부24, 세움터, 법제처에서 직접 확인하세요.

                

            

        


        
        

            

                

                    

                        
                    

                    

                        
구글 앱스 스크립트(GAS) 백엔드 자동 수집 가이드

                        
본 도구에서 검색한 데이터를 구글 시트에 자동으로 누적 저장하는 스크립트 코드입니다.

                    

                


                

                    
사용 방법:

                    
    
                        
  1. 구글 시트(Google Sheets)를 새로 생성합니다.
    2. 
                        
  2. 상단 메뉴에서 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
    3. 
                        
  3. 기존 코드를 모두 지우고 아래의 스크립트 코드를 복사하여 붙여넣습니다.
    4. 
                        
  4. 코드 내 SERVICE_KEY 항목에 본인의 공공데이터 API 키를 입력하고 저장 후 실행합니다.
    5. 
                    

                


                

                    
                    
// 구글 앱스 스크립트 (Google Apps Script) - 공공데이터 API 조회 도구 (건축물대장 예시)
function fetchBuildingRegisterHubData() {
  const SERVICE_KEY = "YOUR_PUBLIC_DATA_API_KEY_HERE"; // 공공데이터포털 인코딩 인증키
  const sigunguCd = "11680"; // 예: 강남구
  const bjdongCd = "10100";  // 예: 역삼동
  const bun = "0825";        // 4자리 맞춤 (예: 825 -> 0825)
  const ji = "0000";         // 4자리 맞춤
  
  const url = `https://apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo?serviceKey=${SERVICE_KEY}&sigunguCd=${sigunguCd}&bjdongCd=${bjdongCd}&bun=${bun}&ji=${ji}&_type=json&numOfRows=100`;
  
  try {
    const response = UrlFetchApp.fetch(url, { muteHttpExceptions: true });
    const json = JSON.parse(response.getContentText());
    const items = json.response.body.items.item;
    
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (!items || items.length === 0) {
      Logger.log("조회된 데이터가 없습니다.");
      return;
    }
    
    // 헤더 작성 (첫 줄)
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(Object.keys(items[0]));
    }
    
    // 데이터 행 추가
    items.forEach(item => {
      sheet.appendRow(Object.values(item));
    });
    
    Logger.log(`${items.length}건 수집 완료!`);
  } catch (e) {
    Logger.log("오류 발생: " + e.toString());
  }
}
