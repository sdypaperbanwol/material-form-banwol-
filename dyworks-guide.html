대양웍스 · 근태 관리

비콘을 못 찍었을 땐,
이렇게 요청하세요

출퇴근 시간을 잘못 눌렀거나 비콘 인식이 안 됐을 때
직접 수정 요청하는 방법을 순서대로 안내합니다

언제 사용하나요? 비콘 인식 오류, 출근과 동시에 퇴근을 잘못 누른 경우, 출퇴근 기록 누락 등 실제 근무 시간과 앱 기록이 다를 때 사용합니다.
신청 가능 기간 · 과거 2주 ~ 오늘
1
Step 1

하단 메뉴에서 요청관리 열기

근태 관리 화면 맨 아래 메뉴에서 요청관리를 눌러 이동합니다.
근태 관리 화면
2
Step 2

내 요청 탭으로 이동

요청관리 화면 상단에서 내 요청 탭을 눌러주세요. (기본은 승인 목록 탭이 열려있어요)
'내 요청' 탭이 보이는 경우만 해당

화면에 '내 요청' 탭이 없는 경우(일반 직원 등), 요청관리 화면에 바로 새 요청 버튼만 보입니다. 이 경우 이 단계는 건너뛰고 다음 단계(새 요청 버튼 누르기)로 넘어가시면 됩니다.
요청관리
3
Step 3

새 요청 버튼 누르기

화면 오른쪽 위에 있는 새 요청 버튼을 눌러 요청 작성 창을 엽니다.
내 요청
4
Step 4

요청 유형 확인

요청 제출 창이 열리면 유형이 출퇴근 변경으로 되어있는지 확인합니다. 이 화면에서 아래로 근무일, 요청 출근/퇴근, 사유까지 순서대로 입력하게 됩니다.
요청 제출
5
Step 5

근무일 선택

근무일 아래의 날짜를 누르면 달력이 뜹니다. 수정하려는 날짜를 선택하고 확인을 누릅니다.
날짜 선택
6
Step 6

요청 출근 시간 입력

요청 출근 밑의 입력 버튼을 누르면 시 → 분 순서로 시간을 고를 수 있어요. 실제 출근한 시간으로 맞춰주세요.
시(時)
분(分)
7
Step 7

요청 퇴근 시간 입력

같은 방식으로 요청 퇴근 입력 버튼을 눌러 시 → 분 순서로 실제 퇴근 시간을 입력합니다.
시(時)
분(分)
8
Step 8

사유 작성 후 제출

사유 칸에 간단한 사유(예: 비콘 누락, 인식 오류 등)를 적고 제출을 누르면 요청이 완료됩니다. 이후 승인권자 확인을 거치면 반영됩니다.
사유 입력 · 제출
✓

제출하면 끝!

제출한 요청은 요청관리 → 내 요청에서 승인/거절 여부를 바로 확인할 수 있습니다.

문의사항은 반월 지원파트로 연락 주세요.
